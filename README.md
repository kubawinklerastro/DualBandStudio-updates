# DualBand Studio — PixInsight update repository

DualBand Studio by Kuba Winkler. In PixInsight: *Resources › Updates › Manage Repositories › Add* and enter

    https://raw.githubusercontent.com/kubawinklerastro/DualBandStudio-updates/main/

then *Resources › Updates › Check for Updates*, apply, and restart PixInsight.
The script appears under *Script › Utilities › DualBandStudio*.
